# V9 Tool — website hồ sơ Meta

Website công khai dành cho ứng dụng cá nhân V9 Tool, sử dụng n8n và Meta Graph API để đăng bài lên các Facebook Page được cấp quyền.

## Các trang

- [Trang chủ](index.html)
- [Chính sách quyền riêng tư](privacy-policy.html)
- [Điều khoản sử dụng](terms.html)
- [Hướng dẫn xóa dữ liệu](data-deletion.html)

## Xuất bản GitHub Pages

Vào **Settings → Pages → Build and deployment → Deploy from a branch**, chọn **main / (root)** rồi **Save**.

Sau khi GitHub Pages kích hoạt, địa chỉ thường là:

- https://thangmai02.github.io/v9-tool-privacy/
- https://thangmai02.github.io/v9-tool-privacy/privacy-policy.html
- https://thangmai02.github.io/v9-tool-privacy/terms.html
- https://thangmai02.github.io/v9-tool-privacy/data-deletion.html

> **Quan trọng:** Nội dung được soạn theo trường hợp sử dụng n8n đăng bài lên Fanpage do chủ ứng dụng quản lý. Chủ ứng dụng cần kiểm tra email liên hệ, các nhà cung cấp dịch vụ tích hợp, dữ liệu và thời gian lưu trữ có phản ánh thực tế hay không trước khi dùng cho Meta App Review. Không lưu token, mật khẩu hay App Secret trên repository này. Việc xuất bản website không đồng nghĩa app Meta được phê duyệt hoặc Live.
